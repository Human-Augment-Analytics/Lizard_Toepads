Code

PACE

Experiment + model record

MLflow

A checkpoint needs its contract

The deployable bundle

Our new candidate contains one frozen H7 ONNX detector, separate newly trained finger/toe dlib predictors, and a manifest describing how they work together.

  • detector.onnx finds oriented digit regions.
  • finger.dat and toe.dat predict nine landmarks each.
  • bundle.json connects classes, files, preprocessing, landmark order and provenance.
  • The packaged inventory adds file sizes and SHA256 hashes.

For this model the contract is BGR, perspective rectification, centered black letterboxing to 512 × 512, and backprojection into the original image.

The research handoff is broader

It also preserves resolved configuration, environment versions, source snapshot, dataset/split references, evaluation results and one reproducible native example.

A newer DINO/HRNet checkpoint may need its own architecture, auxiliary files and adapter. A four-class detector cannot silently replace the current six-class H7 decoder.

One app, several model versions

A newly registered MLflow version does not create a new application or deployment. Refresh Research models, choose Import this version, then Use this version. Import installs a validated catalog entry. Existing analyses retain their selected model identity; compatible weights need no app rebuild. A new architecture may need a new inference adapter.

What passed

  • New finger/toe weights trained from scratch in a scheduled CPU job.
  • 153 package file hashes verified; native example predictions matched across hosts.

  • Two detected objects and 18 landmarks on a withheld full-image derivative.

  • All six prior catalog manifests and existing aliases stayed unchanged.
Research candidate · no promotion

What the result does not establish

The fitting set was small: 49 finger and 36 toe crops. Tests contained 14 finger and seven toe crops. Mean test errors were 11.29 and 16.92 pixels on 512-pixel ground-truth-derived crops.

Those are landmark-only, oracle-box measurements. The frozen H7 detector’s training exposure is unknown. Toe validation contains large failures on specimens 1055 and 1540. A scientifically approved default requires a stronger independent benchmark.

Evaluation + operations

Qualify and operate it

Name owners, freeze the independent benchmark, address weak cases, establish team access, and exercise backup/restore. App restart was tested; full restore was not.

For each change: one issue, a named owner, a small source branch, exact-revision checks and review, and a release receipt. Keep automatic packaging/validation separate from the research decision to promote a default.
